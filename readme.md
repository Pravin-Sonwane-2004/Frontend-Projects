Common Git Commit Keywords
Keyword	Meaning	Example
feat	New feature	feat: add user registration API
fix	Bug fix	fix: resolve null pointer issue
docs	Documentation changes	docs: update setup guide
style	Formatting/UI changes (no logic change)	style: improve navbar spacing
refactor	Code improvement without changing behavior	refactor: simplify service layer logic
perf	Performance improvement	perf: optimize search query
test	Add/update tests	test: add unit tests for user service
build	Build-related changes	build: update Maven dependencies
ci	CI/CD changes	ci: add GitHub Actions workflow
chore	Misc maintenance	chore: clean unused imports
revert	Undo previous commit	revert: remove broken JWT filter
init	Initial project setup	init: setup Spring Boot project
merge	Merge branches	merge: merge dev into main
hotfix	Urgent production fix	hotfix: patch payment API issue
